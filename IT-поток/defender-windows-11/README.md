# Как отключить Microsoft Defender в Windows 11

Актуальный редакционный исходник: [`defender-factchecked.html`](defender-factchecked.html). Черновик WordPress: [запись 11875](https://itpotok.ru/?p=11875&preview=true). Состояние на 30 сентября 2026 года: **черновик**, не опубликован.

## Что входит в папку

- `defender-factchecked.html` — HTML, сохранённый в WordPress.
- `defender-factcheck.md` — проверенные утверждения, первичные источники, редакционные исправления и границы проверки.
- `illustrations.md` — происхождение восьми изображений и правила подписей.

## Редакционное решение перед публикацией

На сайте уже есть опубликованный материал по теме: https://itpotok.ru/disable-defender-antivirus-windows-11/. Перед публикацией нужно решить, обновлять ли эту запись или публиковать новый URL; два одинаковых материала оставлять не следует. Проверить заголовок и предпросмотр в WordPress, работоспособность ссылок на источники и отображение восьми изображений. После публикации сохранить итоговый URL здесь.

## Граница проверки

Статья сверена с документацией Microsoft и источниками иллюстраций. Отключение Defender на тестовой Windows 11, состояние после перезагрузки и восстановление защиты практически не проверялись. Собственных кадров приложения «Безопасность Windows» нет. Эти ограничения нельзя удалять из редакционных материалов или заменять недоказанными утверждениями.
