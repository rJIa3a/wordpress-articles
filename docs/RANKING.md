# Сравнение упоминаний одной цели

Гипотеза: качество выбора места ссылки повысится, если сравнивать упоминания одной цели внутри статьи. Данные прежние: 805 train / 172 dev. Test не оценивался.

Проверены два подхода:

1. Попарное предпочтение: 22 720 обучающих примеров разницы признаков между местами с оригинальной ссылкой и без неё внутри одной пары source-target. Оценка предпочтения дополняет прежний score. Результат хуже — подход отклонён.
2. Относительные признаки: отличие каждого упоминания от максимума и среднего по другим упоминаниям той же цели в статье. Эти признаки вычисляются из текста, без оригинальных ссылок. Их сочетания изучает градиентный бустинг.

## Сопоставимые результаты dev

Во всех строках порог 0.5, максимум одна ссылка на цель в статье.

| Вариант | Предложений | Совпадений абзац+цель | Precision | Recall | F0.5 |
|---|---:|---:|---:|---:|---:|
| Прежняя модель | 942 | 670 | 71,13% | 45,64% | 0,6398 |
| Попарная оценка, вес 0.25 | 942 | 667 | 70,81% | 45,44% | 0,6369 |
| Относительные признаки, прежняя сложность | 939 | 671 | 71,46% | 45,71% | 0,6422 |
| Только увеличение сложности модели | 977 | 692 | 70,83% | 47,14% | 0,6436 |
| Относительные признаки + большая модель | 968 | 703 | 72,62% | 47,89% | 0,6582 |

Последний вариант выбран по dev F0.5. Модель с 15 листьями и 250 итерациями сравнивалась с контролем тех же параметров без относительных признаков. Поэтому эффект нельзя объяснить только увеличением сложности. При одинаковой сложности добавление признаков дало +11 совпадений и меньше предложений.

По сравнению с прежней версией: +33 совпадения, +1,50 п.п. precision, +2,25 п.п. recall. Полные совпадения границ анкора: 531 вместо 516; precision 54,86% вместо 54,78%. По парам страниц без учёта абзаца: precision 78,00%, recall 68,20%.

## Устойчивость

Парный bootstrap по source-статьям, 2000 повторов:

- Разница precision: +1,50 п.п., 95% интервал [−0,14; +3,33].
- Разница recall: +2,25 п.п., интервал [+0,77; +3,83].
- Разница F0.5: +0,0184, интервал [+0,0031; +0,0354].

Это описательная оценка после настройки на dev. Она не учитывает полностью множественный подбор моделей и тематическую зависимость статей. Независимого подтверждения нет, новый holdout всё ещё необходим. Это лексико-контекстный эксперимент, не завершённый нейросетевой прогон.

## Воспроизведение

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=2 python -m city_benchmark.refine --city-morphology --sentence-context
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=2 python -m city_benchmark.ranking
python -m city_benchmark.uncertainty --before refinement-sentences --after refinement-ranking
```

Первый шаг сохраняет обучающие признаки и records без test-источников. Второй проверяет принадлежность источников и сравнивает варианты. Результаты сохраняются отдельно в `local-data/cities/refinement-ranking`. Все результаты, включая проигравшие варианты, сохранены в ranking-results.json.
