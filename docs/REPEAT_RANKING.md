# Выбор места и повторные ссылки

Проверены восемь конфигураций на прежних train/dev-артефактах. Test не использовался.
Фиксированная модель: HistGradientBoosting, 250 итераций, 15 листьев, seed 17.
Новый вариант добавляет сравнение признаков упоминания со средним и максимумом
упоминаний той же цели в том же разделе. Эталонные ссылки в эти признаки не входят.

## Результаты одинакового запуска

| Вариант | Предложений | Совпадений блок+цель | Precision | Recall | Precision точного анкора |
|---|---:|---:|---:|---:|---:|
| Контроль: одна ссылка | 952 | 694 | 72,90% | 47,28% | 71,01% |
| Контроль + повторы с порогом 0,65 | 1026 | 733 | 71,44% | 49,93% | 69,40% |
| Контроль + повторы с порогом 0,8 | 961 | 698 | 72,63% | 47,55% | 70,76% |
| Признаки раздела, одна ссылка | 949 | 693 | 73,02% | 47,21% | 70,71% |
| Признаки раздела + повторы 0,8 | 956 | 697 | 72,91% | 47,48% | 70,50% |

Последний вариант восстанавливает на три сочетания блок+цель больше текущего
контроля, но ухудшает точные анкоры. Это не убедительное улучшение. Проверка
принятия требует не снижать precision ни блока, ни точного анкора: остаётся контроль.
Это дополнительное защитное условие введено после просмотра результатов;
независимым подтверждением оно не является. Новая политика не включена в сервис.

## Ограничение воспроизводимости

Повторный контроль дал 694 совпадения из 952 предложений, тогда как сохранённый
исторический запуск давал 703 из 968. Причина расхождения пока не установлена.
Нельзя приписывать разницу новой политике: внутри текущего запуска все варианты
используют одинаковые данные и окружение, но сравнение с историей требует проверки
версий зависимостей, численных вычислений и контрольных сумм артефактов.
В отчёте сохраняются numpy/sklearn версии и флаг исторического воспроизведения.

## Что улучшено в коде

- Сохраняется причина решения по каждому кандидату: порог, лимит цели,
  уверенность повтора, раздел, расстояние, пересечение анкоров, самоссылка или выбор.
- Проверяется шкала вероятностей: NaN, infinity и score 80 вместо 0,8 отклоняются.
- Добавлены тесты политики повторов, объяснений, порядка и изоляции разделов/целей.
- Все варианты, включая проигравшие, сохраняются для сравнения.

## Воспроизведение

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=2 python -m city_benchmark.repeat_ranking
python -m pytest python_tests -q
```

Нужны сохранённые training-features/training-records из refinement-sentences,
исправленный gold train/dev и исторические результаты refinement-ranking.
Выход: local-data/cities/refinement-repeat-ranking/{results,predictions,scored-dev,decisions}.json.
Следующий шаг — устранить расхождение контрольного запуска, затем сравнить
совместную модель контекста и цели на фиксированных кандидатах. Простое ослабление
ограничения повторов по этому эксперименту не рекомендуется.
