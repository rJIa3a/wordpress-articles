# Пропущенные связи: итерация 10 сентября 2026

Оценка только на прежней подборочной выборке dev (172 статьи), обучение на 805 статьях. Test не оценивался. Независимость новых результатов не заявляется.

## Разбор исходных пропусков

Из 1468 оригинальных пар «абзац + цель» восстановлено 633. Для 302 пропущенных пар выбрана ссылка в другом абзаце; для 418 кандидат найден, но не прошёл порог или пересекается с другим анкором; для 115 кандидат не найден. Это взаимоисключающие причины, сумма — 1468.

В train 1302 пары страниц имеют ссылки более чем в одном абзаце. Поэтому проверено повторение в разных разделах: максимум 2–3 ссылки, расстояние минимум 3 блока, отдельный более строгий порог. Режим сайта по умолчанию не изменён.

По заранее используемому критерию F0.5 выбран повтор с порогом 0,80. Прирост небольшой; статистическая значимость не проверялась. Нельзя представлять его как окончательно достигнутое качество.

Точность полного совпадения границ анкора снизилась с 56,19% до 55,52%. Это отдельная нерешённая задача: улучшение цели и абзаца не гарантирует точный исходный анкор Wikipedia.

## Изменения

Географический разбор отдаёт приоритет Geox при формировании shortlist и разбирает составные названия по частям. Примеры исправленных форм: «Новосибирском», «Переславлю-Залесскому». Это только поиск кандидата; релевантность по-прежнему проверяется отдельно. В сервисе этот разбор применяется к анкорам целей с распознанным городом. Старый benchmark доступен без нового флага для сопоставимости.

Команды:

```bash
python -m city_benchmark.misses
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=2 python -m city_benchmark.refine --city-morphology
python -m city_benchmark.selection --experiment refinement-morphology
```

Результаты новой ветки сохраняются в `local-data/cities/refinement-morphology`, исходные — в `refinement`. Проверка повторов сравнивается на одинаковых scores без переобучения. Режим повторов пока относится только к эксперименту Wikipedia. Обученная модель не перенесена на scoring сайта; полный нейросетевой прогон ещё не завершён.
