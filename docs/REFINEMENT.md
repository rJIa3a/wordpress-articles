Выбор по максимуму F0.5: entity_context_trees, порог 0.5. Precision 70.6%, recall 43.1%; 633 совпадения из 897 предложений. Базовый выбранный вариант: precision 57.3%, recall 45.2%; 663 совпадения из 1157. Улучшение точности сопровождается небольшой потерей полноты.

При пороге 0.8 новый вариант даёт 174 предложения, из них 160 совпадают по абзацу и цели (92.0%), но восстанавливает только 10.9% оригинальных связей. Этот режим нельзя представлять как восстановление всей перелинковки.

Добавлены признаки ближайшего контекста, расстояния, транспорта, биографий, учреждений, позиции и повторов названия. Градиентный бустинг учитывает взаимодействия этих признаков. Предобученная нейросетевая семантика в этом прогоне не использована.

При ручной проверке обнаружены смешение реки Лесной Воронеж с городом Воронеж и рекомендации в перечнях городов. Добавлен признак другой именованной сущности; соответствующая консервативная защита подключена к городскому режиму сервиса. Часть несовпадений с оригиналом (например, Краснокамск → Пермь в разделе География) выглядит содержательно оправданной и требует редакционной оценки.

Модель эксперимента ещё не подключена к production scoring dagorod.ru: редакционные статьи имеют другие цели и распределение признаков. Перенесены только безопасные правила распознавания сущностей.

Воспроизведение: `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=2 python -m city_benchmark.refine`. Результаты и выбор сохраняются отдельно от первоначального отчёта; test predictions не создаются. Для независимого подтверждения следующей версии нужен новый корпус holdout.
