# Контекст предложения: эксперимент

Обучение: 805 статей. Подборочная оценка: те же 172 dev-статьи. Test не оценивался. Ссылки между городами корпуса, не все типы ссылок Wikipedia.

Добавлены признаки отдельного предложения: лексическая близость к целевой статье, положение упоминания, доля предложения в абзаце, положение в скобках и число слов с заглавной буквы. Это не нейросетевой прогон. Границы предложений определяются эвристикой; сокращения могут приводить к неточному разбиению. Анкоры сохраняют исходные позиции.

| Вариант | Предложений | Совпадений абзац+цель | Точность | Полнота | F0.5 |
|---|---:|---:|---:|---:|---:|
| Морфология, без повторов | 904 | 645 | 71,35% | 43,94% | 0,6343 |
| Морфология, ограниченные повторы (предыдущий итог) | 906 | 647 | 71,41% | 44,07% | 0,6353 |
| Контекст предложения, без повторов | 942 | 670 | 71,13% | 45,64% | 0,6398 |

На одинаковом режиме без повторов прирост — 25 совпадений; точность снизилась на 0,22 процентного пункта, полнота выросла на 1,70 пункта. Совпадение точных границ анкоров: 54,78% (516 совпадений), против 55,42% (501) у предыдущего варианта без повторов. Поэтому улучшение полноты не следует называть улучшением всех метрик.

## Неопределённость

Парный bootstrap по исходным статьям, 2000 повторов, seed=17:

- Разница precision: −0,22 п.п., описательный 95% интервал [−2,29; +1,47].
- Разница recall: +1,70 п.п., интервал [+0,58; +2,88].
- Разница F0.5: +0,0055, интервал [−0,0103; +0,0189].

Это описательная проверка на использованном для настройки dev, не независимый статистический тест; тематическая зависимость статей также остаётся. Общий рост качества не подтверждён новым holdout. Вариант сохранён для следующих экспериментов, автоматическое применение не включается.

Исправлена также ошибка экспорта: scored-dev.json теперь содержит оценки выбранной по F0.5 модели, а не последней обученной модели. Исходные результаты экспериментов не перезаписываются.
