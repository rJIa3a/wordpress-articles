# Инструкции для работы над Universal Interlinker

- Отвечай пользователю по-русски. Работай в существующем репозитории и сначала проверяй `git status`; не затирай незакоммиченные изменения.
- Это локальный сервис контекстной перелинковки с планом переноса на VDS. Сначала доводи небольшие проверяемые улучшения до работающего состояния; не перестраивай проект без необходимости.
- Пользователь сам добавляет свои сайты. WordPress импортируй через публичный REST API в режиме чтения. Не подключайся к сайтам, не публикуй и не меняй их содержимое без отдельного явного запроса.
- Рекомендации предназначены для проверки человеком. LLM не может придумывать URL: цель выбирается только из страниц сайта. Не представляй score как вероятность.
- Не запрашивай и не записывай реальные пароли, токены и ключи в Git, вывод команд или документацию. Локальные секреты храни в игнорируемом `.env`; для production проверяй TLS и настройки безопасности.
- После изменений запускай подходящие тесты и, если менялся сервис, проверяй локальный Docker/HTTP. Не выполняй разрушительные Git-команды и не публикуй версии без запроса.
- Исследовательские результаты сохраняй вместе с методикой и проигравшими вариантами. Не подбирай параметры на test и не называй результат на dev независимым улучшением.

Подробная цель, текущее состояние и следующие задачи: [`docs/PROJECT_SPEC.md`](docs/PROJECT_SPEC.md).
