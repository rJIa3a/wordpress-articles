# Редакционная работа для ITpotok.ru

Этот каталог содержит исходники публикаций сайта `itpotok.ru`. Для новой статьи создавайте отдельную папку в `IT-поток/` и начинайте с её `README.md`. Актуальный пример — `IT-поток/defender-windows-11/`.

## Как мы готовили статью

1. Сначала изучили материал конкурента, затем составили структуру ответа на запрос читателя: быстрый выбор способа, шаги, ограничения, проверка результата, возврат настроек и частые вопросы.
2. Спорные утверждения сверяли с первичными источниками, прежде всего с Microsoft Support и Microsoft Learn. Для сторонней утилиты проверяли страницу разработчика. Ссылки и границы проверки сохраняли в `defender-factcheck.md`.
3. Иллюстрации подбирали под конкретный шаг. Проверяли язык интерфейса, что кадр действительно показывает, дату интерфейса и условия использования. Подписывали внешние изображения с активной ссылкой на источник. Не называли их собственными скриншотами.
4. Готовили HTML для WordPress и сохраняли запись черновиком. После сохранения проверяли предпросмотр: заголовки, изображения, подписи, ссылки и отсутствие редакторских пометок. Передавали ссылку на черновик.

## Правила для следующих статей

- Главный приоритет — точный, понятный и полезный материал. Техническое SEO не подменяет редактуру.
- Ведите один актуальный исходник статьи и отдельный файл фактчекинга. Промежуточные версии не отправляйте в репозиторий.
- Для каждого важного способа укажите применимость, ожидаемый результат, ограничения, проверку и возврат к исходному состоянию. Не обещайте результат, который не проверяли.
- Не выдавайте чужие изображения, макеты и снимки веб-страницы за собственные кадры Windows. Если нужного кадра нет, опишите его в редакционных заметках, а не в опубликованном тексте.
- Не публикуйте доступы, токены, `pass.txt`, данные пользователей или внутренние снимки экранов с личной информацией. Репозиторий GitHub публичный.
- Перед публикацией WordPress проверьте, нет ли уже опубликованной статьи на ту же тему, и согласуйте, какую запись обновлять. Черновик и публикация — разные действия.
- Если работа требует управления приложениями безопасности Windows, следуйте ограничениям установленного навыка `computer-use`; практические испытания описывайте только при реально выполненной ручной проверке.

## Где лежит результат

`IT-поток/defender-windows-11/defender-factchecked.html` — актуальный HTML; `defender-factcheck.md` — источники, правки и пределы проверки; `README.md` — состояние записи и указатель на предпросмотр.
